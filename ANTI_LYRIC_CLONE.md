# Anti–lyric-clone rule

**Rule:** Spiritual sequel via **craft dials only** (tempo, bass weight, cut energy, length bed, stamp cadence). Do **not** reuse another artist’s lyric lines, hooks, or distinctive phrases. Original words only.

- Copying or paraphrasing a reference track’s sung lines
- Borrowing a reference’s stamp hook wording
- “Close enough” lyric echoes that a listener would hear as the same song
